# Codex Quota Orb v0.4.9

本版本同时提供 Windows ZIP 与 macOS DMG，两个安装包均由同一版本标签构建。

## 主要更新

- 正确区分“历史 Token 吞吐”与“全部对话最新上下文占用”，不再把累计 Token 当作上下文容量。
- 上下文主卡汇总每个本地对话最后一次有效上下文快照，并显示已占用、总容量、剩余容量和对话数。
- 项目页与对话页增加合计行，可直接和主卡的上下文总量核对。
- “总占比”统一以全部对话最新上下文已占用量为分母，并通过两位小数平衡舍入精确回加至 `100.00%`。
- 修复压缩后的对话被错误显示为 `0`、项目汇总与主卡合计不一致等问题。
- 保留圆形浮窗拖动、右键退出、跟随 Codex、始终置顶、周配额监控及高 DPI / Retina 绘制。

## 数据口径

- **Token 使用详情**：本机历史 `token_count` 记录，反映模型处理量。
- **上下文占用**：每个对话最后一次有效上下文快照中的已占用量与模型窗口容量；同一对话只取最新快照，不累计历史轮次。
- **项目总占比**：项目最新上下文已占用量 ÷ 全部对话最新上下文已占用量。
- **对话总占比**：单个对话最新上下文已占用量 ÷ 全部对话最新上下文已占用量。

## 验证

- Windows 自检与打包在 GitHub Actions 的 Windows 2022 环境完成。
- macOS Swift Release 构建、自检与 DMG 打包在 GitHub Actions 的 macOS 14 环境完成。
- Release 仅在 Windows 与 macOS 两个构建任务同时成功后发布。
