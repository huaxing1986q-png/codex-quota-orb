# Codex Quota Orb v0.4.10

本版本修复 Codex Desktop 升级后配额和详情数据更新变慢的问题，同时提供 Windows ZIP 与 macOS DMG。

## 主要修复

- 本地会话写入由 750ms 尾随等待调整为 250ms 合并，并在持续高频写入时设置 2 秒上限。
- 会话变化后开启 12 秒追赶窗口，以官方请求允许的 2 秒最短间隔重新校准，避免第一次请求早于官方数据发布后再等待 30 秒。
- Windows 与 macOS 请求均明确绕过本地 HTTP 缓存，并发送 `no-cache` / `no-store`。
- Token 历史缓存升级为追加式增量解析：大型活动会话只读取上次完整换行后的新增 JSONL 内容。
- 文件被截断、替换、缓存版本变化或行边界不安全时自动完整重扫，确保增量优化不牺牲统计准确性。
- 保持官方配额、累计 Token 历史和全部对话最新上下文占用三种口径相互独立。

## 验证要求

- Windows 离线解析与刷新策略自检全部通过。
- 使用真实大型本机会话连续读取，确认首次建缓存后，活动文件增长不再触发整文件扫描。
- macOS Swift Release 构建、自检和 DMG 打包由 GitHub Actions 的 macOS 14 runner 完成。
- Release 仅在 Windows 与 macOS 两个平台同时构建成功后发布。

## 数据与隐私

浮窗周配额仍只来自 Codex Desktop 登录状态访问的官方配额端点。本地 JSONL 仅用于 Token 历史和上下文快照；插件不保存访问令牌、账户 ID、原始配额响应、消息正文或工具输出。
