# Codex Quota Orb for Windows

适用于 Windows 10/11，使用原生 WinForms 绘制并启用 Per-Monitor DPI V2，在 4K 与多屏环境下按目标显示器的实际缩放重新渲染。

## 快速安装

1. 解压 `Codex-Quota-Orb-Windows.zip`。
2. 右键 `Install.ps1`，选择“使用 PowerShell 运行”。
3. 安装完成后浮球会立即启动，并默认添加当前用户登录启动项。

如果只想临时运行，双击 `Start Codex Quota Orb.vbs`，不会出现蓝色 PowerShell 后台窗口。

## 操作

- 单击圆球：展开周配额与重置时间。
- 右击圆球：打开原生菜单；选择“退出插件”结束浮球进程。
- 点击周配额区域：打开本机 Codex Token 使用详情。
- 点击“本月总用量”区域：进入“容量结构 / 项目占比 / 对话明细”。
- 下一层点击“返回”或按 `Esc`：回到 Token 使用详情。
- 鼠标移出或点击桌面：自动回缩到原位置。
- `EN` / `中`：切换语言。
- `T`：切换始终置顶。
- `Esc`：回缩；圆球状态下再次按 `Esc` 退出。

## 卸载

运行 `Uninstall.ps1` 删除登录启动项。关闭浮球后，可删除：

```text
%LOCALAPPDATA%\CodexQuotaOrb
```

## 数据与隐私

- 浮球配额读取 Codex 官方周使用量接口。
- 详情页主信息区按本机历史显示本月 Token、本月占累计总量比例、本机累计和当前项目/对话占比；不显示月重置时间或账户版本。
- 官方周配额只显示在浮球与周配额卡；当前上下文容量仍在下一层容量明细中单独计算。
- 上下文容量优先按 Codex Desktop 本机日志中的前台活动会话 ID，读取对应会话最新 `token_count` 中的 `model_context_window` 与输入明细；日志不可用时按最近一次非压缩输入活动回退。
- 项目和对话明细读取 `session_meta` 的会话 ID 与 `cwd`，并关联每个会话的数值 Token 累计。
- Token 详情只统计本机 `.codex` 会话中的数字事件。
- 不保存访问令牌、提示词、聊天正文或原始配额响应。

上下文占用率通常按最新请求的 `input_tokens ÷ model_context_window` 计算。Codex 压缩边界记录若出现输入分项为零、但本轮总量仍为正，程序会按“本轮总量减去输出”恢复压缩后的输入占用，避免错误显示 `0%`；绝不使用会话累计 Token 代替上下文。压缩记录无法可靠拆分缓存与新增输入时，这两项显示为 `—`，并显示原始上下文采样时间。缓存复用属于输入子集，推理属于输出子集；界面不会重复相加。剩余低于 50% 时提示整理无关上下文，低于 10% 时提示总结并新建任务。项目路径、会话 ID 和前台路由 ID 只在内存中即时解析，不写入缓存；程序不读取消息正文为对话命名。
