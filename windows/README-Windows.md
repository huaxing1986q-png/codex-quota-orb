# Codex Quota Orb for Windows

适用于 Windows 10/11，使用原生 WinForms 绘制并启用 Per-Monitor DPI V2，在 4K 与多屏环境下按目标显示器的实际缩放重新渲染。

## 快速安装

1. 解压 `Codex-Quota-Orb-Windows.zip`。
2. 右键 `Install.ps1`，选择“使用 PowerShell 运行”。
3. 安装完成后浮球会立即启动，并默认添加当前用户登录启动项。

如果只想临时运行，双击 `Start Codex Quota Orb.vbs`，不会出现蓝色 PowerShell 后台窗口。

## 操作

- 单击圆球：展开周配额与重置时间。
- 右击圆球：打开原生菜单；选择“退出插件”结束浮球进程。
- 点击周配额区域：打开本机 Codex Token 使用详情。
- 点击“累计上下文用量”区域：进入“上下文结构 / 项目占比 / 对话明细”。
- 下一层点击“返回”或按 `Esc`：回到 Token 使用详情。
- 鼠标移出或点击桌面：自动回缩到原位置。
- `EN` / `中`：切换语言。
- `T`：切换始终置顶。
- `Esc`：回缩；圆球状态下再次按 `Esc` 退出。

## 卸载

运行 `Uninstall.ps1` 删除登录启动项。关闭浮球后，可删除：

```text
%LOCALAPPDATA%\CodexQuotaOrb
```

## 数据与隐私

- 浮球配额读取 Codex 官方周使用量接口。
- 详情页上方统计卡与下方活动图显示本机 Token 历史；中间信息区显示所有本地对话的累计上下文输入，不显示当前活动对话的单次容量、月重置时间或账户版本。
- 官方周配额只显示在浮球与周配额卡；点击中间累计上下文卡可进入上下文结构、项目占比和对话明细。
- 累计上下文按每个会话的数值型 `input_tokens` 增量汇总；缓存复用是输入子集，新增输入等于累计输入减去累计缓存复用。
- 项目和对话明细读取 `session_meta` 的会话 ID 与 `cwd`，并关联每个会话的累计上下文输入。
- Token 详情只统计本机 `.codex` 会话中的数字事件。
- 不保存访问令牌、提示词、聊天正文或原始配额响应。

每个会话优先使用 `total_token_usage` 的累计分项计算增量；旧记录缺少累计分项时，才累加 `last_token_usage` 数值分项。累计计数重置后按新段继续累计。项目页和对话页的“累计占比”都以全部累计上下文输入为分母，并应精确回加到主卡总数。缓存复用属于输入子集，推理属于输出子集，界面不会重复相加。项目路径和会话 ID 只在内存中即时解析，不写入缓存；程序不读取消息正文为对话命名。
